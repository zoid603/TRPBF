# Сервис игровых достижений (Game Achievement Tracker)

Консольное приложение на Python для ведения каталога игр, достижений и прогресса игроков. Состояние приложения хранится в JSON-файлах и сохраняется при выборе пункта выхода.

## Возможности

- просмотр списка зарегистрированных игр и количества достижений в каждой игре;
- просмотр достижений выбранной игры или всего каталога;
- добавление игр и достижений с автоматической генерацией ID;
- отметка достижений как секретных;
- поиск достижений по подстроке без учета регистра;
- сортировка достижений по количеству требуемых действий;
- создание профиля игрока при первой фиксации прогресса;
- поиск пользователя по имени без учета регистра;
- добавление и обновление прогресса игрока;
- расчет процента выполнения с ограничением до 100%;
- определение статуса достижения;
- вывод карточки игрока;
- загрузка и сохранение данных в JSON;
- обработка отсутствующих и поврежденных JSON-файлов.

## Требования

- Python 3.10 или новее;
- зависимости из `requirements.txt`;
- `pytest` для запуска тестов.
- `flake8` для проверки оформления кода.

Приложение использует стандартную библиотеку Python. Файл `requirements.txt` содержит инструменты разработки `pytest` и `flake8`.

## Установка и запуск

Откройте PowerShell и перейдите в каталог проекта:

```powershell
Set-Location project
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

Запустите приложение:

```powershell
python main.py
```

Пути к данным задаются относительно текущего каталога. Запускайте `main.py` из папки `project`, чтобы файлы `data/*.json` находились по указанным путям.

## Меню приложения

| Пункт | Действие |
| --- | --- |
| 1 | Показать список игр и количество достижений |
| 2 | Показать достижения конкретной игры |
| 3 | Показать все достижения |
| 4 | Добавить игру |
| 5 | Добавить достижение к игре |
| 6 | Найти достижения по названию |
| 7 | Отсортировать достижения по сложности |
| 8 | Зафиксировать или обновить прогресс игрока |
| 9 | Показать карточку прогресса |
| 0 | Сохранить изменения и выйти |

При вводе чисел разрешены только неотрицательные целые значения. Дата прогресса вводится в формате `ГГГГ-ММ-ДД`, например `2026-09-15`. Изменения сохраняются в JSON только при выборе пункта `0`.

## Структура проекта

- `main.py` — точка запуска, загрузка данных и консольное меню.
- `games.py` — добавление и поиск игр.
- `users.py` — создание пользователей и поиск по имени.
- `achievements.py` — создание, поиск, сортировка и выбор достижений по игре.
- `progress.py` — расчет процента, статуса, карточки и записей прогресса.
- `storage.py` — загрузка и сохранение JSON-файлов.
- `utils.py` — безопасный ввод неотрицательных чисел и дат.
- `data/` — постоянное хранилище игр, пользователей, достижений и прогресса.
- `tests/` — модульные и smoke-тесты.
- `requirements.txt` — зафиксированные зависимости проекта.

## Формат данных

### `data/games.json`

```json
{
  "id": 1,
  "title": "DOOM"
}
```

### `data/users.json`

```json
{
  "id": 1,
  "username": "PlayerOne"
}
```

### `data/achievements.json`

Достижение связывается с игрой через `game_id`:

```json
{
  "id": 1,
  "game_id": 1,
  "name": "Меткий стрелок",
  "required_actions": 50,
  "is_secret": false
}
```

### `data/progress.json`

Запись прогресса связывает пользователя и достижение:

```json
{
  "id": 1,
  "user_id": 1,
  "achievement_id": 1,
  "completed_actions": 10,
  "record_date": "2026-09-15"
}
```

## Статусы прогресса

- `Не начато` — выполнено 0 действий;
- `В процессе` — выполнено больше 0, но меньше требуемого количества;
- `Получено` — выполнено требуемое количество или больше.

## Тестирование

Из каталога `project` в PowerShell:

```powershell
$env:PYTHONPATH = "."
python -m pytest -q tests
```

Тесты проверяют:

- добавление игр и автоинкремент ID;
- поиск игр по существующему и отсутствующему ID;
- создание и поиск достижений;
- поиск достижений генератором без учета регистра;
- сортировку достижений по сложности;
- расчет процента и все варианты статуса прогресса;
- создание и обновление записи прогресса;
- фильтрацию прогресса по пользователю и достижению;
- создание пользователей и поиск имени без учета регистра.

В тестах используются маркеры `smoke` и `unit`.

## Проверка качества кода

Линтер установлен в виртуальном окружении проекта. Проверять нужно только исходники и тесты, исключая каталог `venv`:

```powershell
$files = @(Get-ChildItem -File -Filter '*.py' | ForEach-Object { $_.FullName }) + @(Get-ChildItem -File -Path tests -Filter '*.py' | ForEach-Object { $_.FullName })
& '.\venv\Scripts\python.exe' -m flake8 $files
```

Команда завершается без замечаний. Запуск `flake8 .` также возможен благодаря исключениям из `.flake8`, но проверка явного списка собственных исходников и тестов остается более прозрачной.

Синтаксис исходников и тестов дополнительно проверен командой `python -m py_compile` без ошибок.
