# Game Achievement Tracker

Консольное приложение для каталога игр, достижений и прогресса игроков. В версии ПР3 словари и списки из ПР2 заменены объектной моделью, а JSON-файлы сохранены в прежнем формате.

## Возможности

- просмотр игр и количества достижений;
- добавление игр и достижений;
- поиск достижений по подстроке;
- сортировка достижений по сложности;
- создание пользователей;
- добавление и обновление прогресса;
- расчет процента и статуса достижения;
- вывод карточки игрока;
- загрузка и сохранение объектных коллекций в JSON.

## Объектная модель

Пакет `models/` содержит четыре сущности:

- `Game` — атрибуты `id`, `title`; строковое представление игры.
- `Achievement` — атрибуты `id`, `game`, `name`, `required_actions`, `is_secret`; методы `is_unlocked()` и `progress_percent()`.
- `User` — атрибуты `id`, `username`; метод `from_data()` для восстановления из JSON.
- `Progress` — ссылки на объекты `User` и `Achievement`, количество выполненных действий и дату; методы `update()`, `percent()`, `status()`.

Связи объектов:

```text
Progress -> User
Progress -> Achievement -> Game
```

Идентификаторы связей используются только на границе хранения. Внутри приложения `Progress` содержит реальные объекты пользователя и достижения, а `Achievement` — объект игры.

## Структура проекта

- `main.py` — консольное меню и сценарии приложения.
- `models/games.py` — класс `Game`.
- `models/achievements.py` — класс `Achievement`.
- `models/users.py` — класс `User`.
- `models/progress.py` — класс `Progress`.
- `models/__init__.py` — публичный экспорт моделей.
- `games.py` — функции работы с `list[Game]`.
- `achievements.py` — функции работы с `list[Achievement]`.
- `users.py` — функции работы с `list[User]`.
- `progress.py` — функции работы с `list[Progress]`.
- `storage.py` — преобразование JSON в объекты и обратно.
- `utils.py` — безопасный ввод чисел и дат.
- `data/` — JSON-файлы приложения.
- `tests/` — тесты объектной модели и бизнес-логики.

## Формат JSON

Формат данных совместим с ПР2. Например, запись прогресса хранит идентификаторы, а не вложенные объекты:

```json
{
  "id": 1,
  "user_id": 1,
  "achievement_id": 1,
  "completed_actions": 10,
  "record_date": "2026-09-15"
}
```

При загрузке `storage.py` связывает `user_id` с объектом `User`, а `achievement_id` — с объектом `Achievement`. При сохранении связи снова преобразуются в идентификаторы.

## Требования и установка

- Python 3.10 или новее;
- `pytest`;
- `flake8`.

```powershell
pip install -r requirements.txt
```

## Запуск приложения

Из каталога `project`:

```powershell
python main.py
```

Пути к данным относительные, поэтому запускать приложение нужно из корня проекта.

## Тестирование

```powershell
$env:PYTHONPATH = "."
python -m pytest -v
```

Текущий результат: `8 passed`.

Тесты проверяют:

- создание объектов `Game`, `User`, `Achievement`, `Progress`;
- атрибуты и строковые представления объектов;
- восстановление `User` через `from_data()`;
- проверку разблокировки и расчет процента;
- поиск и сортировку объектных коллекций;
- обновление существующего объекта прогресса;
- связи `Progress` с `User` и `Achievement`.
